## 1. 产品概述

多角色审批工作台是一个面向企业内部审批场景的综合管理平台，支持多角色协同审批、审批流节点可视化追踪、权限动态校验、操作审计记录及异常预警。目标用户为企业审批管理员、部门审批人和普通申请人，旨在提供真实后台工作台级别的交互深度和数据联动能力。

- 解决传统审批系统中节点状态不透明、越权操作无感知、审批记录难追溯等核心痛点
- 通过本地模拟数据实现全功能闭环演示，无需后端即可体验完整审批流程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 角色来源 | 核心权限 |
|------|----------|----------|
| 超级管理员 | 系统预置 | 全部审批单查看、审批流配置、角色权限管理、异常处理 |
| 部门审批人 | 角色分配 | 本部门审批单审批、驳回、转办 |
| 财务审批人 | 角色分配 | 财务类审批单审批、金额校验 |
| 普通申请人 | 默认角色 | 提交申请、查看本人申请状态 |

### 2.2 功能模块

1. **工作台主页**：统计概览卡片、异常提醒横幅、申请列表（含筛选与搜索）
2. **申请详情页**：审批流节点时间线、当前节点角色权限面板、操作记录时间轴、审批操作区

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台主页 | 统计概览卡片 | 待审批数、已审批数、异常数、今日提交数，点击可筛选对应状态 |
| 工作台主页 | 异常提醒横幅 | 展示越权操作、缺审批人、记录异常等告警，支持逐条关闭和一键清除 |
| 工作台主页 | 申请列表 | 表格展示所有申请，支持按状态/类型/部门筛选，关键词搜索，点击行进入详情 |
| 工作台主页 | 统计图表 | 审批趋势折线图、类型分布饼图、部门处理效率柱状图 |
| 申请详情页 | 审批流节点 | 时间线展示所有审批节点，标注当前节点、已通过、被驳回、待审批状态 |
| 申请详情页 | 角色权限面板 | 展示当前节点所需角色及审批人，高亮越权操作和缺失审批人 |
| 申请详情页 | 操作记录 | 时间轴展示所有操作历史，记录为空时显示空状态警告 |
| 申请详情页 | 审批操作区 | 通过/驳回/转办按钮，根据当前用户角色动态启用或禁用，越权时显示警告 |

## 3. 核心流程

用户登录工作台后，在主页查看统计概览和异常提醒，通过筛选或搜索定位目标申请，点击进入详情页。详情页中审批流节点、角色权限和操作记录三方联动：选中某节点时，权限面板切换至该节点对应的角色和审批人，操作记录自动筛选至该节点相关操作。若当前用户角色不匹配节点所需角色，操作按钮禁用并显示越权警告；若节点无审批人，显示缺审批人告警；若操作记录为空，显示空状态提示。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1e293b) + 琥珀橙 (#f59e0b) 作为强调色，搭配石板灰 (#64748b) 中性色
- 按钮风格：圆角 6px，主操作用实心琥珀橙填充，次要操作用描边样式
- 字体：标题使用 Noto Sans SC 600/700，正文使用 Noto Sans SC 400，数据数字使用 JetBrains Mono
- 布局风格：左侧固定导航栏 + 顶栏面包屑 + 主内容区卡片式布局
- 图标风格：线性 Lucide 图标，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台主页 | 统计概览卡片 | 4列网格卡片，图标+数字+趋势箭头，hover 微浮起阴影 |
| 工作台主页 | 异常提醒横幅 | 顶部横向滚动横幅，红/橙/黄三色分级，带关闭按钮 |
| 工作台主页 | 申请列表 | 斑马纹表格，状态标签圆角徽章，行 hover 高亮，分页器 |
| 工作台主页 | 统计图表 | 三栏网格，Chart.js 折线/饼/柱图，暗色主题 |
| 申请详情页 | 审批流节点 | 纵向时间线，节点圆点带图标和状态色，当前节点脉冲动画 |
| 申请详情页 | 角色权限面板 | 卡片内表格，越权行红色底色，缺失审批人行黄色底色+虚线边框 |
| 申请详情页 | 操作记录 | 纵向时间轴，每条记录含操作人/时间/动作/备注，空状态骷髅屏+警告文案 |
| 申请详情页 | 审批操作区 | 底部固定操作栏，主/次按钮组，越权时整体变灰+红色警告图标 |

### 4.3 响应式

- 桌面优先设计，1920px 为主断点
- 1280px 以下统计卡片由4列变2列，图表由3列变1列
- 768px 以下导航栏折叠为汉堡菜单，表格改为卡片列表

### 4.4 无障碍

- 所有交互元素支持键盘导航
- 状态标签使用 ARIA role 标注语义
- 图表提供数据表格替代视图
- 异常提醒使用 role="alert" 实时播报
